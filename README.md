# Monday, Reviewed in One Line

Entry for the [Monday, Reviewed in One Line](https://make.fun/c/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) bounty on make.fun.

The program writes the funniest one-line review of my own Monday — under
200 characters — to `/output/entry.txt`:

> Monday: 1 star. My coffee went cold during a meeting about a meeting, and my motivation is still stuck in traffic.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later. `OUTPUT_DIR` overrides the default `/output`
directory (handy for local runs).
